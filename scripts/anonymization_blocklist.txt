# Anonymization policy — THE CARRIER IS NOT HERE.
#
# WHAT THIS IS FOR. None of the strings this guard looks for is a secret, a
# credential or sensitive personal data. They are crufty developer and machine
# detail that simply should not appear anywhere in this public tree. The guard
# exists to keep that cruft out, not to protect anything.
#
# This repository tracks NO such strings. The blocklist the guard reads lives
# outside this repository, in the developer's private companion repo, and reaches
# the guard as scripts/anonymization_blocklist.local.txt — a gitignored symlink
# created by a per-machine setup step. This file records the POLICY that governs
# what belongs in that carrier; it is not itself a carrier and defines no tokens.
#
# TRIAGE RULE: list ONLY strings that are crufty developer or machine detail —
# things with no business in a public tree. Public, doc-derivable, or functionally
# required identifiers are KEPT in the source and MUST NOT be listed; blocklisting
# one breaks the thing it names.
#
# ADMISSION RULE: a token ships only if the string could plausibly appear in
# this repository's future content. A list that accretes by "it costs nothing"
# logic becomes unreviewable, and an unreviewable control is not a control.
#
# DISCRIMINATION RULE: prefer the narrowest segment that cannot occur in
# legitimate prose. Common words are rejected even when they appear in the
# violation — a guard that fires on documentation is a guard that gets bypassed.
# Tokens containing a colon or a slash are rejected because a word boundary does
# not behave around them the way an author expects.
#
# RECONSTRUCTION RULE: prose that says what KIND of string an entry is, how it
# was chosen, or what public string it extends can reconstruct it while passing
# every literal check. Such prose belongs in the private carrier, never here.
#
# RE-TRIAGE TRIGGER: the triage record is why each entry is there. If that
# judgment is ever in doubt, the OWNER may inspect the carrier and re-triage. A
# rule whose justification is a property of what it withholds cannot be falsified
# from inside the rule; this sentence is the falsification path.
